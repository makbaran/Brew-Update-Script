<h1 style="text-align:center;">Brewing-it-Updater</h1>
<p style="text-align:center;">Simple shell script that updates brew, outdated files, upgrades, auto removes unneeded packages, cleans up orphaned packages, and checks system for potential problems.</p>

<h2 style="test-align:left;">Prerequisites</h2>
<p style="text-align:left;">Make sure that you are on a Mac and have brew installed!</p>
<p style="text-align:left;">To install brew you can go to [brew.sh](https://brew.sh/).</p>

<h2 style="text-align:left;">Installation</h2>

<p style="text-align:left;">Now you can clone this repo by copying this command into your terminal `git clone https://github.com/makbaran/Brewing-it-Updater.git`</p>

<p style="text-align:left;">Go into the new folder: `cd Brew-it-Updater`</p>

<p style="text-align:left;">Then give script executable rights: `chmod +x brew.sh`</p>

<p style="text-align:left;">Now run script `./brew.sh`</p>

<p style="text-align:left;">Voila, now you can update brew with just one command!</p>
